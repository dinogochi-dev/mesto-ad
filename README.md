# Mesto
Mesto - проектная работа по курсу "Веб-разработчик" от Яндекс.Практикум.

## Команды

- `npm run dev` - запуск локального сервера
- `npm run build` - сборка проекта
- `npm run deploy` - публикация проекта на Pages
- `npm run preview` - предпросмотр собранного проекта
